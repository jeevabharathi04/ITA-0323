# Task 05 (Q5): Destination-Sequenced Distance-Vector (DSDV) Routing

## 1. Mechanics of DSDV
DSDV is a proactive, table-driven distance-vector routing protocol based on the Bellman-Ford algorithm, enhanced to eliminate routing loops:
1. Every node maintains a routing table listing:
   `[Destination, NextHop, Metric (Hops), SequenceNumber, InstallTime]`
2. **Destination Sequence Numbers:** Generated by the destination node itself (strictly monotonically increasing even numbers).
3. **Loop-Freedom Guarantee:** A route with a higher sequence number is always preferred. If sequence numbers are equal, the route with lower metric (fewer hops) is chosen.

---

## 2. Settling Time to Prevent Route Flapping
When a topological change occurs, advertisements with higher sequence numbers propagate along different paths. To prevent broadcasting suboptimal routes, nodes calculate a **Settling Time** (average arrival delay variance) before forwarding new routing updates.
