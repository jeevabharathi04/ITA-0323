# Task 03 (Q3): Cellular Networks vs Mobile Ad-Hoc Networks (MANETs)

| Criterion | Cellular Networks | Mobile Ad-Hoc Networks (MANETs) |
| :--- | :--- | :--- |
| **Infrastructure** | Heavy fixed infrastructure (Base Stations, BSC/RNC, Core Network, Fiber backhaul). | Autonomous, infrastructure-less; nodes self-assemble dynamically. |
| **Routing Topology** | Single-hop wireless between Mobile and Base Station; routing is wired/core. | Multi-hop wireless; every mobile node acts as an intermediate router. |
| **Cost & Deployment** | Massive CapEx/OpEx; requires spectrum licensing and site acquisition. | Zero infrastructure cost; operates on unlicensed ISM bands; instantaneous setup. |
| **Failure Vulnerability** | Base station failure incapacitates the entire cell. | Highly resilient; self-healing dynamic mesh topologies reroute around failed nodes. |
| **QoS Guarantees** | Deterministic QoS via centralized scheduling and resource reservations. | Best-effort QoS; variable latency and throughput due to dynamic contention. |
